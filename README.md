# Beethoven studiedag 2026 — roadshow

Deze map is een zelfstandige website voor GitHub Pages. `index.html` is de startpagina. Foto's, video en PDF's staan in dezelfde publicatiemap, zodat de links ook voor bezoekers werken.

## Publiceren met GitHub Pages

1. Maak een **aparte repository** aan voor deze website. Publiceer deze map niet in een repository die ook andere Beethoven-projectbestanden bevat.
2. Zet **alle bestanden en de map `fotos`** in de hoofdmap van de repository. Laat de bestandsnamen zoals ze zijn, omdat `index.html` ernaar verwijst.
3. Upload de volledige map met Git, GitHub Desktop of de GitHub-website. De glossy in deze publicatiemap is een webvriendelijke kopie van circa 5 MB; het oorspronkelijke PDF-bestand blijft in de map `Studiedag/naslagwerk` staan.
4. Kies in de repository **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.
5. De website verschijnt op `https://<gebruikersnaam>.github.io/<repositorynaam>/`. Wacht tot GitHub Pages meldt dat de publicatie gereed is en test de links op de website.

## Toegang en delen

GitHub Pages is standaard publiek toegankelijk, ook als de bronrepository privé is. Afgeschermde Pages-sites zijn alleen mogelijk onder specifieke GitHub Enterprise Cloud-instellingen. Publiceer de foto's, film en PDF's dus alleen na een bewuste keuze over de doelgroep. Als de site publiek is, kunnen ontvangers alle lokale bronlinks zonder Avans-inlog openen.

Externe links naar Brainport-evenementen en Brainport Academy verwijzen naar websites buiten deze map. De beschikbaarheid daarvan hangt af van die websites.
